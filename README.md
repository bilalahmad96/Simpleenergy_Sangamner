## 🌐 How to Deploy to Vercel in 1 Minute

1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **"Add New Project"** $\rightarrow$ select or drag & drop this folder (`simpleenergy-sangamner-reviews`).
3. Click **"Deploy"**.
4. Your website will be live at `https://your-showroom.vercel.app`!
   * Customers open: `https://your-showroom.vercel.app`
   * Owner opens: `https://your-showroom.vercel.app/admin`
